# To-Do List App

A simple and responsive web-based To-Do List application developed using HTML, CSS, and JavaScript.

This project was created as a college mini project to practice JavaScript DOM manipulation, event handling, and basic frontend web development.

## 📌 About the Project

The To-Do List App allows users to add tasks, mark tasks as completed, and delete tasks from the list.

The application provides a simple interface for managing tasks directly in the browser.

---

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks using the **Enter** key
- Empty task validation
- Responsive design
- Simple and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## ⚙️ How It Works

```text

    ↓
Click "Add Task"
